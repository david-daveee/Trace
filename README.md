# Trace — тренировки на Android

Версия 0.14.0 личного дневника тренировок для Android 8.0 и новее. Работает без аккаунта и интернета. Интерфейс на русском и английском.

## Возможности

- Планы, мои программы, текущая тренировка и календарь прогресса.
- Программы Шейко, включая 12-недельный цикл к соревнованиям, и базовая схема Матвея Злата.
- Максимумы на всю программу и автоматический расчёт процентных весов.
- Независимые отметки подходов, отмена и редактирование веса и повторений.
- Управление тренировкой из системной медиапанели Android.
- Импорт программ и резервное копирование. Данные тренировок хранятся на телефоне.

## Открыть проект

Открой корневую папку в Android Studio. Для сборки нужны JDK 17 и Android SDK 35. После синхронизации Gradle выбери устройство и нажми Run.

Для сборки из терминала с настроенными `JAVA_HOME` и Android SDK:

```powershell
./gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/`. Личные резервные копии, локальные настройки, результаты проверок и ключи подписи исключены из Git.

## Обновление 0.8

В библиотеку автоматически добавляется программа «Матвей Злат · турник и брусья». Источник: https://www.youtube.com/watch?v=AeB4znuGuSo, схема по русскому переводу сообщения №68 https://forum.steelfactor.ru/index.php?page=3&showtopic=46569. Это открытая схема 2018 года, не Advanced Beginner. 12 занятий — организация дневника, не авторский срок.

Три занятия в неделю, 3 или 4 подхода по 5–8 повторений. Дополнительный вес задаётся отдельно для подтягиваний и брусьев. Перед сохранением пользователь подтверждает фактические повторы последнего подхода по порядку плана; прибавки 5/2,5/1,25/0,5 кг для 8+/7/6/5 повторений, ниже пяти — без прибавки. Следующие дни пересчитываются, история сохраняет фактические веса. Уведомление открывает приложение для подтверждения результата.

## На телефоне

Приложение называется **Trace**. Готовый установочный файл: `outputs/Trace.apk`.

1. В «Мои планы» нажми **Изменить максимумы** под программой. Исходные 180/130/190 кг взяты из таблицы, это не оценка твоих текущих возможностей. Введённые значения применяются сразу ко всей программе.
2. На главной нажми «Начать следующий день» и разреши уведомления.
3. Отмечай подходы в приложении или в развёрнутом уведомлении. После отдыха нажми «К подходу», после выполнения — «Готово».
4. Для упражнения без веса в исходной таблице укажи рабочий вес. Ноль означает выполнение без дополнительного отягощения.
5. После последнего подхода нажми «Завершить»: только тогда день попадёт в историю и откроется следующий.

Таймер отдыха не издаёт сигнал и не переключает подход автоматически. Настройки видимости на экране блокировки зависят от телефона. После принудительной остановки приложения системой/пользователем открой его, чтобы восстановить панель. Прогресс сохранён.

## Импорт других программ

CSV — UTF-8, разделитель `;` (поддерживается также TSV). XLSX — первый лист, без формул. Заголовки и порядок:

```csv
день;упражнение;подходы;повторения;вес
День 1;Присед;3;5;60
День 1;Жим лёжа;3;5;40
День 2;Пресс;3;10;0
```

Одинаковое название дня объединяет строки. Каждая строка — отдельный блок, поэтому повтор одного упражнения позднее в занятии сохранится. Десятичная запятая допустима. Пустой вес означает выбор веса в зале. Шаблон экспортируется из библиотеки.

Произвольная разметка Excel не распознаётся автоматически. XLS Шейко поддерживает формулы умножения максимума и округления из предоставленного файла. XLSX с формулами отклоняется, чтобы не подменять пересчёт устаревшими сохранёнными значениями. JSON сохраняет процентную модель программы.

## Открыть в Android Studio

Нажми **Open** и выбери папку проекта. Для этой машины настроена Java 17 в `.tools/jdk`, SDK находится в стандартной папке Android. Дождись Gradle Sync, выбери подключённый телефон и нажми Run.

Если Android Studio предлагает JDK: Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK → выбери JDK 17 из `.tools/jdk` (не встроенную Java 25).

На Windows при ошибках Gradle из-за кириллицы открой тот же проект через созданный путь `%TEMP%/podhod-project`. Это ссылка на эту папку, а не отдельная копия.

## Сборка и проверки

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap.ps1
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

`build.ps1` выполняет сборку APK, unit-тесты и Android Lint. Временные пути без кириллицы обходят проблему Java/Gradle на Windows. Исходный код: Java 17 и Android Views; Gradle 8.11.1, AGP 8.9.2, compile/target SDK 35. APK для личного тестирования подписан debug-ключом; публикация в Google Play не выполнялась.

24 unit-теста проверяют все 178 исходных формул, пересчёт всех 16 дней и текущего занятия, сохранение выполненных и ручных весов, независимость программ, валидацию максимумов, паузу, отдых, отмену, завершение дня и импорт XLS/CSV/XLSX. Проверка на телефоне рендерит реальные экраны и проверяет обновление веса в уведомлении и его сохранение. Исходные данные восстанавливаются после проверки.

### Цикл Шейко из sheyko.xlsx (Trace 0.14.0)

В каталог добавлен отдельный план «Шейко · 12 недель к соревнованиям»: 24 подготовительных и 11 предсоревновательных занятий, всего 1 251 подход. Соревнования №36 показаны как событие после расписания: исходник не задаёт для них попыток. Исходные максимумы 175 / 150 / 180 кг можно заменить своими; процентные веса округляются до 0,5 кг, подсобные веса не выдумываются.

Извлечение: `scripts/extract_sheyko_cycle.py`, результат: `app/src/main/assets/sheiko_competition.json`. Все 832 веса сверены с сохранёнными значениями XLSX. В `План соревн. 3!D110` краткая запись тяги на 60% задаёт 3 повторения, подробные ячейки `E112:F112` — 2. Перенесены подробные ячейки, расхождение сохранено в `outputs/sheiko-cycle-audit.json`. Таблица пользователя не изменялась.

Добавление в каталог идемпотентно и не меняет существующие программы, историю и занятия. Unit-тесты проверяют весь цикл, округление, пересчёт и сохранность данных. На телефоне проверены оба языка и точное равенство данных до/после обновления за исключением новой записи каталога.

Каждое действие сохраняется синхронно в приватное хранилище приложения. История хранит снимок подходов. Сервера, аналитики и разрешения на интернет нет. Перед удалением приложения сохрани файл через Настройки → Сохранить копию. Восстановление заменяет текущие данные только после подтверждения.

Источник программы: пользовательский файл `Sheyko_podgotovka_plan_kmc_mc.xls`, Б. И. Шейко. Извлечение сверено с сохранёнными значениями Excel; исходный файл не изменялся.
